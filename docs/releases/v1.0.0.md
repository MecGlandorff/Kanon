# Kanon v1.0.0 release notes

Status at candidate preparation: not published. These notes apply only to the
exact candidate commit and tarball recorded by the content-addressed candidate
evidence. Remote cross-platform validation and a later explicit publication
authorization are still required.

## Public package

Kanon v1.0.0 is a dual-host plugin distribution for Codex CLI and Claude Code,
not a JavaScript library or global terminal CLI. The package contains separate
host manifests, a shared dependency-free ESM runtime, compatibility workflows,
and exactly six canonical stable skills: `orient`, `resume`, `verify`, `status`,
`steer`, and `aswitch`.

The compatibility workflows remain `brief`, narrowly scoped `ask`, `verify`,
`resume`, `refresh`, and `todo`. Notice mode remains explicit, advisory, and
non-enforcing. No production lifecycle hook is shipped.

## Compatibility and installation

Node.js majors 20, 22, 24, and 25 are supported. The artifact includes Bash and
PowerShell wrappers. macOS is locally exercised; native Linux and Windows
conformance require the validate-only remote matrix and remain Unknown until it
passes.

Install the exact package without lifecycle scripts into a user-controlled
plugin directory, then configure the host to load the complete installed
package root:

```text
npm install --ignore-scripts --prefix <plugin-directory> @mecglandorff/kanon@1.0.0
```

Host-specific native plugin-data and loader configuration remain platform
settings and must be verified against the installed host version.
