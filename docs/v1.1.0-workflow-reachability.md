# Kanon v1.0.0 Public Workflow Reachability

This Phase 0 inventory maps every published workflow to the executable
JavaScript modules that its installed wrapper statically retains. It describes
the immutable `v1.0.0` tag at commit
`21c6d1df2cd2676354a9de6bab96e4651781a608`; the measured package sources are
byte-identical on the refactor branch at the time of this inventory.

This is package reachability, not semantic execution. A module belongs to a
workflow closure when Node loads it through a static import after the shared
dispatcher selects a runtime bin. The Bash and PowerShell wrappers, skill
documents, manifests, and other non-JavaScript package files are explicit
artifact roots outside this module-closure measurement.

## Method

The checked source paths are the canonical form of the generated `runtime/`
paths. `collectRuntimeDependencies()` in
`scripts/lib/artifact-files.js` follows contained relative imports with a
visited set.
The stable runtime's package import `#kanon-continuity` is resolved explicitly
from `package.json` and treated as a second root. The two root sets are:

- stable and compatibility-read workflows: `src/v1/bin/kanon.js` plus
  `src/continuity/engine.js`;
- compatibility-write workflows: `bin/kanon-write.js`.

Each root itself and all of its recursively reached relative imports count
once. File bytes and physical lines are summed from canonical sources. The
artifact conformance checks separately prove that every generated runtime
module is byte-equivalent to its canonical source.

## Intersection and deletion boundary

The closures intersect only at `src/continuity/engine.js`, which is 1,189
lines and 30,616 bytes. Their union is exactly the 81 shipped runtime
JavaScript modules measured in the v1.0.0 baseline: 23,620 lines and 609,074
module bytes.

Consequently, 53 modules totaling 11,256 lines and 289,632 bytes are retained
only by `refresh` and `todo` in the published artifact. This identifies the
installed legacy-removal boundary; it does not prove those canonical source
files are unused by repository tests or development tooling. The continuity
engine cannot be deleted with the write closure because stable `resume`,
`verify`, and `steer` still import it.

## Reproduction and regression evidence

Confirm first that the measured implementation paths still match the immutable
release tag:

```sh
git diff --exit-code v1.0.0 -- \
  package.json bin src runtime skills scripts/lib/artifact-files.js
```

After inspecting the invoked helper, reproduce the closure metrics with:

```sh
node --input-type=module <<'NODE'
import fs from "node:fs";
import path from "node:path";
import {
  collectRuntimeDependencies,
  stableRuntimeCanonicalSources
} from "./scripts/lib/artifact-files.js";

const root = process.cwd();
const manifest = JSON.parse(fs.readFileSync("package.json", "utf8"));
const continuity = manifest.imports["#kanon-continuity"].slice(2);
const closure = (entries) => Array.from(new Set(entries.flatMap((entry) => [
  entry,
  ...collectRuntimeDependencies(root, entry)
]))).sort();
const metrics = (files) => files.reduce((total, relative) => {
  const contents = fs.readFileSync(path.join(root, relative));
  const text = contents.toString("utf8");
  total.lines += text.length === 0
    ? 0
    : text.split(/\r?\n/).length - Number(text.endsWith("\n"));
  total.bytes += contents.byteLength;
  return total;
}, { files: files.length, lines: 0, bytes: 0 });
const stable = closure(["src/v1/bin/kanon.js", continuity]);
const write = closure(["bin/kanon-write.js"]);
const union = Array.from(new Set([...stable, ...write])).sort();
console.log({
  stable: metrics(stable),
  write: metrics(write),
  overlap: stable.filter((file) => write.includes(file)),
  union: metrics(union),
  union_matches_shipped:
    JSON.stringify(union) ===
    JSON.stringify(stableRuntimeCanonicalSources(root))
});
NODE
```

Expected output, apart from ordinary object formatting, is:

```text
stable: { files: 28, lines: 12364, bytes: 319442 }
write: { files: 54, lines: 12445, bytes: 320248 }
overlap: [ 'src/continuity/engine.js' ]
union: { files: 81, lines: 23620, bytes: 609074 }
union_matches_shipped: true
```

The focused regression in `test/v1-types.test.js` binds all twelve workflow
surfaces to these two closures, verifies their sole intersection, and proves
that their union equals the shipped canonical-source allowlist:

```sh
node --test \
  --test-name-pattern="public workflows have two exact shipped runtime closures" \
  test/v1-types.test.js
```
